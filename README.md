# Governorates of Egypt Weather Application

A JavaFX application that displays weather information (temperature, humidity, and wind speed) for different governorates in Egypt using weather API data.

## Features

- Real-time weather data for Egyptian governorates
- Displays temperature, humidity, and wind speed
- Modern JavaFX user interface
- Interactive map or list view of governorates

## Prerequisites

- Java 17 or higher
- Maven
- Internet connection (for API access)

## Technologies Used

- JavaFX 17.0.6
- Jackson JSON processing
- JSON Simple


## Setup and Installation

1. Clone the repository:
```bash
git clone https://github.com/saidsabry131/Governorates-of-Egypt-weather.git
```

2. Navigate to the project directory:
```bash
cd Governorates-of-Egypt-weather
```

3. Build the project using Maven:
```bash
mvn clean install
```

4. Run the application:
```bash
mvn javafx:run
```
